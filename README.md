# Proyecto Django – Blog

Este es mi **primer proyecto desarrollado con Django**, creado como parte de mi proceso de aprendizaje en desarrollo backend con **Python**.

El proyecto consiste en un **blog básico**, que me permitió entender cómo funciona Django por dentro y cómo se estructura una aplicación web real.

## 🎯 Objetivo del proyecto

El objetivo principal de este proyecto fue aprender:

- Cómo crear un proyecto desde cero con Django
- Cómo funciona el patrón **MTV (Model - Template - View)**
- Manejo de rutas (URLs)
- Creación de modelos y uso de la base de datos
- Uso de migraciones
- Renderizado de templates HTML
- Flujo de trabajo con Git y GitHub

Mi meta a largo plazo es **trabajar como desarrollador backend utilizando Python**, y este proyecto representa mi primer paso en ese camino.

## 📝 Funcionalidades

- Creación de un proyecto Django desde cero
- Estructura base de una aplicación
- Sistema de blog:
  - Posts
  - Vistas
  - Templates
- Conexión con base de datos SQLite
- Servidor de desarrollo integrado de Django

## 🛠 Tecnologías utilizadas

- Python

- HTML

- SQLite

## 📦 Requisitos

Para ejecutar el proyecto es necesario tener instalado:

- django=6.0.1
- django-environ=0.12.0
- django-tailwind=4.4.2
- pip
- Entorno virtual (recomendado)

## 🔧 Instalación y ejecución

1. Clonar el repositorio:
```bash
git clone https://github.com/tu-usuario/tu-repositorio.git
```
2. Acceder al directorio del proyecto
3. Crear un entorno virtual
4. Activar el entorno virtual
5. Instalar dependencias
6. Aplicar migraciones
7. Ejecutar el servidor: python manage.py runserver
8. Abrir el navegador: http://127.0.0.1:8000/

## 📂 Estructura del proyecto

- `manage.py`  
  Archivo principal para ejecutar comandos de Django.
- `/core`  
  Configuración principal del proyecto Django (settings, urls, wsgi, asgi).
- `/blog`  
  Aplicación principal del proyecto donde se desarrolla la lógica del blog.
- `/templates`  
  Contiene los templates HTML utilizados en el proyecto.
- `/theme`  
  Archivos relacionados con el diseño y estilos del sitio.
- `/env`  
  Entorno virtual del proyecto.
- `db.sqlite3`  
  Base de datos SQLite utilizada durante el desarrollo.
- `requirements.txt`  
  Lista de dependencias del proyecto.
- `.gitignore`  
  Archivos y carpetas ignorados por Git.
